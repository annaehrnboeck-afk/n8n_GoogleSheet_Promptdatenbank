# Projektname
n8n_GoogleSheet_Promptdatenbank

# Projektziel
Eine tabellenblattbasierte Sammlung von Prompts mit einer Web App zum Suchen und Finden von Prompts.

# Verwendete Tools
- Google Sheets
- Google Apps Script

# Workflow
1. Google Sheets als Datenbasis anlegen und mit Prompts füllen
2. In der Web-App den passenden Prompt anhand von Filteroptionen suchen und finden.
3. Regelmäßig die Prompts kurieren.

Beschreibung der einzelnen Schritte zum Anlegen:

1. Google Sheets als Datenbasis anlegen und mit Prompts füllen
2. In Google Sheets über Erweiterungen -> Apps Script ein neues Projekt öffnen
3. Neues Projekt anlegen und "Prompt Finder" nennen
4. In Code.gs den Inhalt der Code-Datei einfügen
5. Neue Datei hinzufügen (Typ: HTML), Index.html benennen und den entsprechenden Code einfügen
6. Über Deploy/Bereitstellen eine neue Bereitstellung anlegen, einen Namen vergeben und bereitstellen
   <img width="1373" height="956" alt="Bildschirmfoto 2026-09-08 um 10 10 32" src="https://github.com/user-attachments/assets/de397fc1-161d-487e-836d-b41434940548" />
8. Die generierte HTML-Adresse kopieren und im Browser aufrufen
<img width="774" height="622" alt="Bildschirmfoto 2026-09-08 um 10 10 48" src="https://github.com/user-attachments/assets/3d98ec11-376b-4a0f-9d13-5ceaaa07d3cb" />
9. Falls die Web App nicht sofort funktioniert: auf "Advanced" klicken, den unteren Link erneut aufrufen und alle nötigen Freigaben erteilen
