# n8n_GoogleSheet_Promptdatenbank
Eine Tabellenblattbasierte Sammlung von Prompts mit Web App zum Suchen und Finden von Prompts

Diese Datenbank funktioniert auf Basis von Google Sheets -> Erweiterungen -> Apps Script

In App Script ein neues Projekt anlegen - Name "Prompt Finder"
In Codes.gs den Inhalt der Codes Datei einfügen
Datei hinzufügen -> HTML -> Index.html - Code aus Datei einfügen

Auf Deploy/Bereitstellen gehen - neue Bereitstellung - Name vergeben - Bereitstellen/Deploy

HTML Adresse kopieren und in Browser aufrufen

Wenn es nicht gleich funktioniert auf "Advaned" drücken und nochmal unten auf den unteren Link und alles freigeben.
